# Bundled Unicode Fonts and Licenses

This directory includes bundled Noto fonts to provide out-of-the-box Unicode rendering support in nametag generation.

## Included fonts
- `NotoSans-Regular.ttf`
- `NotoSansArabic-Regular.ttf`
- `NotoSansHebrew-Regular.ttf`
- `NotoSansEthiopic-Regular.ttf`
- `NotoSansCJK-Regular.ttc`

## Sources
- Noto Fonts repository: https://github.com/notofonts/noto-fonts
- Noto CJK repository: https://github.com/notofonts/noto-cjk
